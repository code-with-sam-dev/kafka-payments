# Security

This is teaching code. It demonstrates messaging and ordering behaviour, and it
is deliberately simple in places where production code would not be.

**Do not deploy it as is.** Among other things it has no authentication, no
authorisation, no transport security, and no rate limiting, because adding them
would obscure the concept each stage exists to teach.

## Reporting a vulnerability

If you find something that would harm someone who ran this locally, or a
dependency with a known advisory, please report it privately through GitHub's
[security advisory form](https://github.com/code-with-sam-dev/kafka-payments/security/advisories/new)
rather than opening a public issue.

You will get an acknowledgement within a few days. There is no bounty; this is
a free educational project.
